## PolyNexus
PolyNexus is an interactive, pixel-art 3D web simulator that demystifies PCOS genetics and pharmacology. By blending rigorous genomic data with a nostalgic retro aesthetic, users can explore 29 risk loci on a dynamic DNA helix, visualize biological pathways, and simulate how precision therapies intervene in the insulin-androgen cycle.
